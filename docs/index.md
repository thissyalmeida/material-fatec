# 🎓 PORTAL ACADÊMICO

Este portal foi desenvolvido utilizando **Material for MkDocs** e reúne todos os materiais das disciplinas ministradas pela Profª Me. Thissiany Almeida.

O projeto faz parte do **Fatec Academic Framework**, um framework acadêmico open source voltado para organização de conteúdos didáticos.

## 👩‍🏫 Sobre a Professora

Sou **Profª Me. Thissiany Almeida**, docente da Fatec Registro.

Neste portal você encontrará materiais, cronogramas, avaliações, projetos e recursos das disciplinas ministradas ao longo dos semestres.

Meu objetivo é disponibilizar um ambiente organizado, moderno e acessível para apoiar o processo de aprendizagem.
